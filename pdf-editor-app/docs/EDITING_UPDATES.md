# 편집 기능 보완 — 2026-09-22

## AI 필기

- 사각형·원·형광펜의 문자 경계 스냅 및 화살표 끝점 스냅을 Tools&Filters와 공통 함수로 계산한다. 자유 곡선 펜은 입력한 경로를 유지한다.
- `plan_annotations`로 대상 페이지와 페이지별 최소 추가 요소 수를 먼저 정한다.
- `verify_annotations` 및 최종 완료 직전 검사에서 실제 AI 생성 요소의 존재와 페이지별 개수를 확인한다. 누락 시 보완을 요청하고, 단계 제한에 도달하면 미완료로 보고한다.
- 기존 형광펜 40개 적용 제한을 제거했다. 취소되거나 작업 문서가 바뀌면 대기 중인 필기를 적용하지 않는다.
- 이 검사는 계획의 적용 여부를 확인한다. 필기 내용의 의미적 정확성·사용자 요구의 완전한 해석까지 자동 보장하는 검사는 아니며, AI 지침에도 내용 검토를 요구한다.

## 유휴 자동 저장

- PDF와 PDF로 표시 중인 PPT/PPTX는 마지막 키보드·포인터·스크롤 활동 또는 편집 후 30초가 지나면 변경 내용을 저장한다.
- 입력 중인 텍스트는 서식 정보와 함께 확정한 뒤 저장한다.
- 파일 선택·Office 변환·저장 대화상자·드래그·기존 저장 작업 중에는 실행하지 않는다.
- 저장 중 생긴 추가 편집은 미저장 상태로 남겨 다음 자동 저장에서 처리한다. 실패하면 상태를 표시하고 다음 유휴 시간에 다시 시도한다.
- Electron은 기존 파일 저장 경로를 사용하고, 브라우저 환경은 기존 워크스페이스 백업 경로를 사용한다. 이미지 원본에 PDF 데이터를 덮어쓰지 않도록 이미지 모드에는 유휴 파일 저장을 적용하지 않는다.

## PPT/PPTX 텍스트 서식

- Office 저장 서비스에서 텍스트의 `spans`와 전체 기본 서식을 함께 읽어 PowerPoint 텍스트 run으로 저장한다.
- 부분 굵게·밑줄·취소선, 겹치는 범위의 서식 덮어쓰기, 기본 서식 해제, 줄바꿈 이후 문자 위치를 처리한다.
- PPTX와 PPT 각각 실제 바이트로 저장한 뒤 다시 열어 서식이 보존되는 회귀 테스트를 통과했다.

## 검증 명령

- `npm run typecheck`
- `npm run test:core`
- `npm run test:annotations` — 공통 스냅, 51개 형광펜 전체 적용, 계획 누락, 실패/취소 처리
- `npm run test:ui` — 자동 저장 시간·활동 연기·중복 방지·미확정 텍스트·모달 차단·실제 저장 리비전 경합 포함
- `npm run test:pdfjs`
- `npm run build`
- backend에서 `gradlew.bat test --tests '*OfficeEditFormattingTest' --offline`

Office 저장 서버 코드가 변경되므로 실행 중인 백엔드는 재시작해야 새 저장 방식이 적용된다. 이미 서식이 유실된 파일은 편집 데이터가 남아 있거나 서식을 다시 적용한 상태에서 재저장해야 한다.

## 통합 설정

- 상단 설정 버튼 또는 Ctrl+,로 열기. 기존 Alt+D도 지원.
- PDF 편집·웹 서퍼·코드 에디터·플러그인·단축키 탭의 공간 비율(1~10)을 즉시 반영하고 저장.
- 화면 테마, 사용자 테마 색상, 필기 색상과 사용자 팔레트를 한 화면에서 변경. Alt+Shift+방향키 색상 선택 유지.
- 플러그인 활성화 상태 기억: 체크 시 마지막 상태 복원, 해제 시 다음 실행부터 모두 비활성화. 현재 실행 중인 플러그인에는 즉시 영향을 주지 않음.
- 설정은 변경 즉시 로컬에 저장되며 다시 실행해도 유지됨.

## 단축키·Office 복원·터미널 도킹 수정

- Alt+방향키는 텍스트/화살표 도구 선택 여부와 무관하게 글꼴·화살표 크기를 조절한다. 위/오른쪽은 증가, 아래/왼쪽은 감소. Alt+Shift+방향키 색상 선택과 분리.
- 터미널 플러그인 실행은 도킹 영역을 열며 왼쪽/아래/오른쪽 이동 중 PTY와 편집기 인스턴스를 유지한다.
- Office 변환 결과의 응답 파일명이 달라도 원본 문서에서 계산한 동일한 키로 필기를 저장·복원한다. 그룹 필기는 자식까지 편집 가능한 모델로 복원한다.
- 편집 데이터 저장 실패를 성공으로 처리하지 않는다. 미편집 Office 원본 백업 완료를 기다린다.
- 회귀 검증: Electron에서 PPT/PPTX 열기 경로(변환·저장소 응답 fixture), 텍스트 서식과 그룹 복원, 터미널 도킹 중 동일 세션 유지. 실제 사용자 문제 파일의 복구 여부는 별도 확인이 필요하다.

## PPTX 한글 굵기 보존

- PowerPoint의 Noto Sans KR 가변 글꼴 PDF 내보내기에서 Thin(100)이 선택되는 문제를 변환 전용 Regular(400)/Bold(700) 고정 글꼴로 보정. 원본 PPTX 및 시스템 설치 글꼴은 변경하지 않음.
- 첨부한 강화학습 2장 PPTX의 34페이지를 PDF.js로 렌더링해 전후 확인. 제목, 본문, 강조 문장의 굵기 구분 복원.
- 적용하려면 변경된 백엔드를 재시작한 뒤 PPTX를 다시 열어 PDF를 새로 변환해야 함.

## 하단 터미널·저장 화질

- 하단 터미널은 편집 영역 전체 폭을 사용하고 높이는 영역의 최대 60%로 제한. 위치를 옮겨도 같은 PTY 유지.
- 통합 설정의 저장 화질: 1~3배, 0.25 단위, 기본 2배. 재시작 후 유지.
- PDF 필기 이미지, PPT/PPTX의 새 필기/화살표 이미지, 이미지/PPT 내보내기에 적용. 기존 이미지와 원본 벡터·텍스트를 다시 압축하지 않음. 파일 내용에 따라 용량 차이가 작을 수 있음.
- PPT/PPTX 저장 화질 적용에는 새 백엔드 재시작 필요.

## 문서 텍스트 선택

- 선택 도구(S)에서 PDF 원본 글자를 드래그해 선택하고 Ctrl+C로 복사. PPT/PPTX도 PDF 변환 후 동일하게 동작.
- 글자와 필기가 겹친 부분은 Alt를 누르고 기존 필기를 선택. 빈 영역에서는 기존 도형 선택 유지.
- 페이지·배율·문서·도구 변경 시 선택 레이어 정리. 스캔 이미지처럼 텍스트 정보가 없는 영역은 OCR 없이 선택할 수 없음.
- 검증: 실제 Electron 마우스 드래그, Alt 전환, 선택 정리, PPT/PPTX 열기 후 원본 텍스트 레이어 표시.

- 드래그 선택: 동일 위치의 중복 텍스트 제거. 선택 사각형은 하나의 합쳐진 경로로 칠해 중첩 영역의 색이 진해지지 않음. 다른 위치에 반복된 글자는 유지.
