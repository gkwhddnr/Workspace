## 2026-10-16 · 편집·저장·플러그인 통합 정리

- UI 재질의 데이터 검증·화면 반영·영속화를 분리했습니다. 재질 미리보기와 옵션 카드의 실제 배경 대비가 같은 글자색 계산 함수를 사용하며, 반투명 배경은 부모 배경과 합성합니다. 설정 제목과 버튼 안내는 실제 단축키 `Alt+D`로 통일했습니다.
- PDF/PPT/PPTX 저장에서 중복된 Blob → Base64 인코딩을 `utils/bytes.ts`로 통합했습니다. 파일 저장 성공과 편집 백업 실패를 구분하고, 새 파일의 백업은 선택한 파일명을 사용합니다. 저장 취소·쓰기 실패·저장 도중 추가 편집이 있을 때 종료하지 않도록 보호합니다.
- 텍스트 입력과 확정된 필기의 위치·글꼴 기준을 맞추고 텍스트 상자 배경을 투명하게 고정했습니다. 가이드 캔버스는 표시 크기와 실제 픽셀 크기를 구분하며, 선택 도구의 주석 핸들이 원문 텍스트 선택보다 우선합니다.
- 모든 플러그인을 탭에 표시합니다. 우클릭으로 활성/비활성을 전환하고, 드래그 위치 미리보기와 탭 순서 저장을 지원합니다. 내부 탭 드래그와 외부 파일 드래그는 전용 MIME을 기준으로 구분합니다.

구조와 검증 범위는 [편집기 리팩토링 안내](EDITOR_REFACTOR.md)에 정리합니다. 자동 UI 검사는 모의 API와 문서 fixture를 사용하며 실제 외부 AI 서비스와 사용자 원본 문서의 결과를 보장하지 않습니다.

검증 완료: `npm run verify` 전체 및 백엔드 OfficeGeometry/OfficeEditService/OfficeSaveQuality 검사. 글꼴 준비 후 DOM·캔버스 기준선을 비교하도록 회귀 검사를 보완했습니다. Vite CJS API·PDF.js eval·큰 청크 경고는 남아 있습니다.

## 2026-10-16 · 저장 좌표 보존

PPT/PPTX의 텍스트 상자 기본 여백·문단 간격·자동 글자 축소를 정리하고 한글/영문 글꼴 그룹을 명시했습니다. 펜·화살표 PNG의 렌더링 여백 및 픽셀 크기와 슬라이드 이미지 배치 범위를 일치시켰습니다. 슬라이드 크기와 필기 기준 페이지 크기를 각 축으로 환산하며, 잘못된 페이지 크기는 조용히 무시하지 않고 거부합니다. PPT 그룹 내부 필기도 재귀적으로 저장합니다.

PowerPoint를 사용할 수 있으면 미리보기 PDF도 같은 엔진으로 변환하며, 사용할 수 없으면 LibreOffice로 대체합니다. 변환 엔진 및 설치 글꼴에 따른 원문 표시 차이는 발생할 수 있습니다. PDF 주석 저장은 페이지의 회전·자르기 영역을 역변환하여 필기 위치를 보존합니다.

검증: OfficeGeometryTest 및 기존 OfficeEdit/OfficeSaveQuality 검사, `npm run test:export-geometry`. PPT/PPTX 가로형·와이드·세로형의 저장 후 앵커/필기 픽셀과 PDF 두 크기·네 회전 각도의 재렌더링 위치를 검사합니다. 사용자 첨부 스크린샷에 해당하는 원본 바이너리 파일은 별도로 비교하지 않았습니다.

## 2026-10-13 · v1.7.0 개발 브랜치 작업 정리

### UI Material Lab

Stitch MCP 의존성에서 선택 AI 코파일럿 기반 JSON 재질 생성으로 전환했습니다. 단일 이미지·폴더 전체 분석, 붙여넣기, 참고 키트, Magnific 링크, 생성 중단, 큰 미리보기, 다시 만들기와 디테일 수정을 제공합니다. 두 적용 방식과 버튼 변형은 선택·저장되어 즉시 편집기에 적용됩니다.

영역별 재질 수정은 일반 버튼과 도구 버튼을 독립적으로 처리합니다. 적용된 디자인은 실시간 반영합니다. 전체 UI 초기화와 이전 디자인 복구, 디자인 보관함을 제공합니다. 텍스트·아이콘·한글·설정·드롭다운 대비와 색상 견본을 보완하고 상단 활성 탭을 구분합니다.

### Editorial Diagram와 AI

예제 JS 1.8.1에 페이지별 원문 요약·파일별 저장, 미작성 페이지 순차 처리, 자동 요약, 저장 결과 보호와 명시적 업데이트를 반영했습니다. 핵심 요약과 독립적인 관계·반응형 배치·연결선, 코드의 분기·반복·상태 변화, 용어 뜻풀이를 제공합니다.

파일명과 본문 문맥으로 웹 출처를 검증하여 GPI/SARSA/displacement의 무관한 의미를 제외합니다. 관련 출처를 여러 개 표시하고 확보한 발췌·초록을 번호 인용과 함께 정리합니다. 코드 에디터 지침과 Editorial 지침은 별도 저장합니다.

학교·기관 Chat Completions 제공자 등록·삭제, 기본 목록 복원, 제공자·모델·키 영속화를 지원합니다. 이미지 입력 형식은 제공자별로 변환합니다. 실제 제공자의 이미지 지원 여부와 사용량은 별도로 확인해야 합니다.

### 문서 편집 및 웹

PDF 필기 텍스트를 확대 배율과 기기 픽셀 비율에 맞춰 다시 렌더링하고 브러시 미리보기·색상 팔레트·설정 위치를 정리했습니다. 스캔 이미지 붙여넣기를 지원하고 분할 경계 방향키 이동을 막았습니다. 웹 출처 URL 연속 이동과 웹뷰 준비 전 대기·주소 동기화를 보완했습니다.

### 문서와 검증

README, 외부 AI API, Editorial 지침, Gradient UI Kit 분석, UI Material Lab 안내, 리팩토링 기록을 갱신했습니다. 이전 MCP 문서는 현재 안내로 연결합니다. 자동 테스트는 모의 AI 응답을 사용하며 실서비스의 생성 품질이나 비용을 검증하지 않습니다. 새로 생성한 패키지의 배포·설치는 이 작업에 포함하지 않습니다.
