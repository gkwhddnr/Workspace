# 단축키 및 조작 안내

기준: Workspace Pro v1.8.0 · 2026-10-16

단축키 모달과 단축키 탭은 `src/config/shortcutsGuide.ts`의 같은 내용을 표시합니다. 아래 안내는 `useAppShortcuts`, `useEditorShortcuts`, PDF 텍스트 입력 및 플러그인 탭의 실제 처리 기준입니다.

## 설정·파일·편집

| 단축키 | 동작 |
| --- | --- |
| `Alt+D` | 설정 열기 (기본 안내) |
| `Ctrl+,` | 설정 열기 (보조, 입력창에서도 사용 가능) |
| `F1` / `?` | 단축키 도움말 모달 |
| `Ctrl+O` | 파일 열기 |
| `Ctrl+S` | 현재 문서 저장. Office 원본 모드는 PPT/PPTX에 필기 반영 |
| `Ctrl+Shift+S` | 다른 이름으로 PDF 저장 |
| `Ctrl+Shift+F` | 파일 정리·플래튼 모달 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 필기 요소 복사 / 잘라내기 / 붙여넣기. 선택한 원문 텍스트는 시스템 복사 우선 |
| `Delete` / `Backspace` | 선택 필기 삭제 |
| `←` / `→` | PDF 이전 / 다음 페이지 |

일반 입력창·텍스트 편집 중에는 파일 열기·도구 전환 등 전역 단축키 대부분을 처리하지 않습니다. 편집 완료 후 사용하세요. PDF 관련 단축키는 PDF 화면이 열려 있을 때 동작합니다.

## 도구와 크기·색상

| 단축키 | 동작 |
| --- | --- |
| `S` / `P` / `H` / `T` | 선택 / 펜 / 형광펜 / 텍스트 |
| `Q` / `C` / `E` / `I` | 사각형 / 원 / 지우개 / 이미지 |
| `1` / `2` / `3` | 꺾임 화살표 두 종류 / 일반 화살표 |
| `[` / `]` | 선 두께 1씩 감소 / 증가 |
| `Shift+[` / `Shift+]` (`{` / `}` 입력) | 화살표 머리 크기 1씩 감소 / 증가 |
| `-` / `=` | 글꼴 크기 2씩 감소 / 증가 (입력 중 제외) |
| `Alt+↑` / `Alt+→` | 글꼴·화살표 크기 1씩 증가 |
| `Alt+↓` / `Alt+←` | 글꼴·화살표 크기 1씩 감소 |
| `Alt+C` | 사용자 색상 선택 |
| `Alt+Shift+←/→` | 색상 목록에서 한 칸 이동 |
| `Alt+Shift+↑/↓` | 색상 목록에서 네 칸 이동 |

크기는 도구별 최소·최대값으로 제한됩니다. 텍스트 입력 중 `Alt+방향키`는 글꼴 크기를 1씩 조절합니다.

## 텍스트 입력·선택

- `Enter`: 줄바꿈. `Ctrl+Enter` 또는 체크 버튼: 입력 완료. `Escape`: 입력 취소.
- 선택한 글자에 `Ctrl+B`: 굵게, `Ctrl+U`: 밑줄, `Ctrl+Shift+X`: 취소선.
- 텍스트 상자 배경은 완전 투명으로 고정되며 배경 투명도 조절은 제공하지 않습니다.
- 선택 도구 `S`는 이미 선택된 주석의 핸들을 먼저 검사합니다. PDF 원문은 드래그해 선택·복사할 수 있고, `Alt`를 누르면 원문 선택을 건너뛰어 주석을 조작합니다.
- 지원 도구에서 `Ctrl+드래그`로 텍스트·도형 경계 스냅을 사용합니다.

## 플러그인 탭·참고 이미지

- 모든 설치 플러그인이 탭에 표시됩니다. 활성은 초록 점, 비활성은 빨간 점입니다.
- 활성 탭 좌클릭: 화면 열기. 우클릭: 활성/비활성 전환. 키보드 메뉴 키 또는 `Shift+F10`으로도 전환합니다.
- 탭을 좌클릭한 채 드래그해 삽입 미리보기 위치에 놓습니다. 순서는 재시작 후에도 유지됩니다.
- 탭에 초점이 있으면 `←/→`, `Home/End`로 탐색합니다. 비활성 플러그인은 활성화한 뒤 실행하세요.
- UI Material Lab의 파일 선택은 단일 이미지, 폴더 선택은 폴더 내 지원 파일을 받습니다. `Ctrl+V`로 참고 이미지를 붙일 수 있습니다. 생성 요청 시 선택한 AI 제공자로 자료를 보내며 API 사용량이 발생합니다.

## 저장 안내

저장 취소·쓰기 실패 또는 저장 중 추가 편집이 있으면 종료를 계속하지 않습니다. 디스크 저장은 성공했지만 편집 백업이 실패한 경우 별도 상태를 표시합니다. 원본 글꼴·Office 변환 엔진에 따른 표시 차이는 [리팩토링 안내](EDITOR_REFACTOR.md)를 참고하세요.
