# Conversion fonts

Workspace Noto Sans KR is a renamed static derivative of Noto Sans KR, licensed under the adjacent SIL OFL 1.1 license.

The source installed variable font has a default wght axis of 100 (Thin). PowerPoint PDF export on this machine exported Thin outlines even for normal and bold runs. These static instances use wght=400 (Regular) and wght=700 (Bold), preserving the source outlines at those weights. No synthetic outline thickening is applied.

Only a disposable PPTX copy replaces the exact Noto Sans KR family reference, including theme references. Run bold flags, sizes, positions and original files remain unchanged. Fonts are registered for the conversion session and removed afterward; installed fonts are not replaced.

Generated with fontTools.varLib.instancer.instantiateVariableFont. Name IDs 1/16 use Workspace Noto Sans KR; IDs 2/17 use Regular or Bold; IDs 3/4/6 and OS/2 weight/style and head.macStyle identify each static face. Source: NotoSansKR-VF.ttf (Adobe 2014–2021).
